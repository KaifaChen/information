# information scripts — Supplementary Materials of *On the Constraint Equations of Information*

This directory contains the numerical-verification scripts and data of the paper *On the Constraint Equations of Information: Derivation, Completeness, and Dynamics of the Four Functionals* (submitted with the paper as supplementary material).

## Files and their roles in the paper

| File | What it verifies | Paper section |
| :--- | :--- | :--- |
| `order_structure_n4_check.py` | **Part 12**: the rank/nullity table of the constraint matrix (m = 3..7) — three feature-gradient rows (local readings of H, ΔS, A) plus the normalization row form a 4×m matrix; the numerical rank is computed | §5.1 |
| `脚本/kx_lattice.py` | Single-cell two-variable Shannon-lattice closure test (T-K1: five identities; T-K2: six quantities determined by three parameters; T-K3: inter-axis collinearity table) | §5.2 |
| `结果/route_func3.tsv` | Input data of `kx_lattice.py`: a code-domain function-level unit table (92 qualified units, add-1 smoothing) | §5.2 |

## How to run

```bash
# Rank/nullity table (§5.1)
python order_structure_n4_check.py        # Part 12 output appears at the end

# Lattice-identity verification (§5.2)
python 脚本/kx_lattice.py                 # output is also written to 结果/kx_lattice.txt
```

Dependencies: Python 3 + NumPy (`order_structure_n4_check.py`); `kx_lattice.py` uses only the standard library. No other third-party packages are required.

## Reproducibility conventions

- `order_structure_n4_check.py`, Part 12: for each m ∈ {3,…,7}, the random seed is fixed at 0; three distributions P, Q, R are drawn from Dirichlet(0.5); the three features are [H(P), D_KL(P‖Q), 1 − √JS(P,R)/ln 2]; central-difference step 1e-6; numerical-rank tolerance 1e-10. One generic point per m — the open-set argument guarantees that a single generic point suffices to exhibit the rank for each m.
- `kx_lattice.py`: input `route_func3.tsv` (add-1 smoothing); results are locked after two byte-identical runs; the T-K1 criterion is that the maximum deviation of the five identities is < 1e-12.
